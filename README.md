# E-commerce Sales Analysis Using SQL

## Project Overview
This is my first SQL project. I am using MySQL to analyze e-commerce sales data.

## Project Objective
The objective is to understand customers, products, orders and payments using SQL queries.

## Tools Used
- MySQL
- MySQL Workbench
- GitHub

## Database Tables
1. Customers
2. Products
3. Orders
4. Order Items
5. Payments

## Analysis Questions
- How many customers are there?
- What are the total sales?
- Which product sells the most?
- How many orders does each customer place?
- Which payments are pending?

## Learning Outcomes
- Creating database tables
- Using Primary Keys and Foreign Keys
- Writing SQL queries
- Joining multiple tables
- Performing sales analysis
